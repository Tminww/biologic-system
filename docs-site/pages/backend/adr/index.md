# ADR Index

`ADR` (Architecture Decision Record) фиксирует архитектурные решения, контекст, альтернативы и последствия.

## Принятые ADR

1. `ADR-0001` Слоистая архитектура и правила зависимостей
2. `ADR-0002` UUID v7 и soft delete как инварианты модели
3. `ADR-0003` Единый формат ошибок RFC 9457
4. `ADR-0004` Контракт пагинации и фильтрации для серверных таблиц
5. `ADR-0005` Унифицированные DTO-контракты CRUD
6. `ADR-0006` JWT-аутентификация через HttpOnly cookies
