# `sample_statuses` — статусы образцов

## Поля

- `id (uuid, DEFAULT uuidv7())` — Идентификатор.
- `code (text, NULL)` — Технический код статуса.
- `name (text, NOT NULL)` — Наименование статуса.
- `created_at (timestamptz, NOT NULL, DEFAULT CURRENT_TIMESTAMP)` — Время создания.
- `updated_at (timestamptz, NOT NULL, DEFAULT CURRENT_TIMESTAMP)` — Время обновления.
- `deleted_at (timestamptz, NULL)` — Мягкое удаление.

## Нормативные коды

| code | name | Комментарий |
| --- | --- | --- |
| `pending` | На регистрации | Образец создан в рамках направления, ожидает приёмки в лаборатории. |
| `registered` | Зарегистрирован | Образец принят регистратором. Проставляется `received_at`, вычисляется `deadline`. |
| `rejected` | Брак | Образец признан непригодным при приёмке. Терминальный статус. |
| `in_progress` | На исследовании | Оператор лаборатории начал работу с образцом. |
| `analyzed` | Обработан | Автоматически: все исследования по образцу завершены. |
| `completed` | Закрыт | Начальник лаборатории подтвердил завершение, новые исследования запрещены. Терминальный статус. |

## Допустимые переходы

| Из | В | Инициатор |
| --- | --- | --- |
| — | `pending` | Система (создан в рамках направления). |
| `pending` | `registered` | Регистратор. |
| `pending` | `rejected` | Регистратор (брак при приёмке) или доктор в лаборатории. |
| `registered` | `in_progress` | Оператор лаборатории. |
| `in_progress` | `analyzed` | Система (все исследования завершены). |
| `analyzed` | `in_progress` | Система (назначены новые исследования). |
| `analyzed` | `completed` | Начальник лаборатории (подтвердил завершение). |

## Каскадные эффекты

:::warning
Переход `pending -> rejected` должен каскадно закрывать активные исследования этого образца: исследования переводятся в `research_statuses.rejected`, причина отмены фиксируется в `change_log.diff` как `cancellation_reason = sample_rejected`.
:::
