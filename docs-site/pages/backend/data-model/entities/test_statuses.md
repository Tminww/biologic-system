# `test_statuses` — статусы испытаний

## Поля

- `id (uuid, DEFAULT uuidv7())` — Идентификатор.
- `code (text, NULL)` — Технический код статуса.
- `name (text, NOT NULL)` — Наименование статуса.
- `created_at (timestamptz, NOT NULL, DEFAULT CURRENT_TIMESTAMP)` — Время создания.
- `updated_at (timestamptz, NOT NULL, DEFAULT CURRENT_TIMESTAMP)` — Время обновления.
- `deleted_at (timestamptz, NULL)` — Мягкое удаление.

## Нормативные коды

| code | name | Комментарий |
| --- | --- | --- |
| `queued` | Запланировано | Автоматически создаётся при назначении исследования. |
| `in_progress` | Выполняется | Доктор приступил к проведению испытания. |
| `completed` | Выполнено | Доктор завершил испытание и получил результаты. |
| `rejected` | Отклонено | Испытание отменено доктором / начальником лаборатории / системой. Терминальный статус. |

## Допустимые переходы

| Из | В | Инициатор |
| --- | --- | --- |
| — | `queued` | Система (создано при назначении исследования). |
| `queued` | `in_progress` | Доктор / Начальник лаборатории. |
| `in_progress` | `queued` | Доктор / Начальник лаборатории (возврат в очередь). |
| `in_progress` | `completed` | Доктор / Начальник лаборатории (внесён результат). |
| `in_progress` | `rejected` | Доктор / Начальник лаборатории (решение не проводить испытание). |
| `queued` | `rejected` | Доктор / Начальник лаборатории / Система (решение не проводить испытание). |
