# Работа с направлениями и образцами

## Общий поток

1. Санитарный врач на объекте формирует образцы и направление.
2. Материалы доставляются на регистрацию.
3. Регистратор создает или импортирует направление и образцы.
4. Для каждого образца назначаются типы и цели исследования.
5. Образцы передаются в лаборатории на выполнение исследований.

## Сценарий ручного ввода

1. Открыть раздел направлений.
2. Создать направление.
3. Добавить образцы и заполнить обязательные поля.
4. Проверить корректность связей (объект, врач, статус).
5. Сохранить запись.

## Сценарий после импорта

1. Проверить список импортированных направлений.
2. Убедиться, что образцы прикреплены к направлениям.
3. Назначить или скорректировать типы образцов.
4. Назначить цели исследования.

## Контрольные точки качества данных

1. Отсутствуют пустые обязательные поля.
2. Корректно выставлены даты приема и статусы.
3. Нет дубликатов направлений или образцов.
