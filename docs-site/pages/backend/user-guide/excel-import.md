# Импорт из Excel

## Назначение

Импорт используется для массового создания направлений и образцов из подготовленного файла.

## Типовой процесс

1. Подготовить Excel-файл в согласованном формате.
2. Загрузить файл в интерфейсе регистратора.
3. Выполнить предварительную валидацию данных.
4. Запустить импорт.
5. Проверить результат и список ошибок (если есть).

## Рекомендации по файлу

1. Соблюдать имена и формат колонок.
2. Использовать однородный формат дат и времени.
3. Не оставлять пустыми обязательные поля.
4. Избегать дублирующихся записей.

## Поведение системы при ошибках

1. Некорректные строки должны возвращаться с деталями ошибки.
2. Ошибки API отдаются в формате `application/problem+json`.
3. Пользователь должен видеть, какие строки можно исправить и повторно загрузить.
