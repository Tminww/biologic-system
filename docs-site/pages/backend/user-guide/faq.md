# FAQ

## Почему запись не видна в списке после удаления?

Используется мягкое удаление: запись получает `deleted_at` и исключается из стандартных выборок.

## Почему не проходит импорт Excel?

Чаще всего причина в формате колонок, датах или пустых обязательных полях.

## Почему frontend не может выполнить действие?

Действие может быть запрещено текущей ролью пользователя (`role-based` доступ в v1).

## Почему значения времени выглядят иначе на разных серверах?

Система использует timezone-aware поля (`timestamptz`), представление времени зависит от клиента и его настроек отображения.
