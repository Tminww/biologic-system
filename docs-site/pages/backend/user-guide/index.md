# Руководство пользователя

Этот раздел описывает пользовательские сценарии в лабораторной информационной системе.

## Разделы

1. `Роли и права`: кто что может делать в системе.
2. `Работа с направлениями и образцами`: основной операционный поток.
3. `Импорт из Excel`: массовое создание направлений и образцов.
4. `Исследования, протоколы, заключения`: завершение цикла исследований.
5. `FAQ`: частые вопросы и типовые проблемы.
