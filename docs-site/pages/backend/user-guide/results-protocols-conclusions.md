# Результаты, протоколы, заключения

## Этапы процесса

1. Лаборатория выполняет исследования по образцу.
2. В систему вносятся тесты и результаты.
3. Формируется протокол.
4. По протоколу создается заключение.

## Работа с результатами

1. Для каждого теста фиксируется значение, норма и комментарий.
2. Статусы обновляются последовательно по бизнес-процессу.
3. При необходимости добавляются рекомендации.

## Работа с протоколом

1. Протокол получает номер в рамках года (`year_no`).
2. Фиксируется дата выпуска (`issued_at`).
3. Сохраняется информация о подписи и копиях документа.

## Работа с заключением

1. Заключение связано со статусом заключения.
2. Допускается комментарий по результату.
3. Финальный статус должен быть прозрачен для frontend.
