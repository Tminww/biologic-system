## Единая терминология

| Термин | Описание |
| --- | --- |
| Филиал | Территориальное подразделение организации |
| Лаборатория | Подразделение внутри филиала, выполняющее определённый вид исследований |
| Объект | Источник образцов (имеет название и адрес) |
| Направление | Сопроводительный документ от санитарного врача со списком образцов и информацией о времени сбора и дедлайнах |
| Образец | Конкретный материал, привезённый на регистрацию (вода, смыв, продукт питания и т.д.) |
| Проба | Часть образца, которая попадает в лабораторию на исследование |
| Тип образца | Категория образца (например: вода питьевая, смыв, продукт питания) |
| Цель исследования | Программа проверки образца в конкретной лаборатории; один образец может иметь несколько целей исследования |
| Показатель | Параметр, который измеряется в образце определенного типа для конкретной цели исследования |
| Норма показателя | Допустимое значение показателя, с которым сравнивается результат исследования |
| Испытание | Измерение одного показателя в рамках исследования пробы образца |
| Исследование | Совокупность испытаний по определенной цели исследования |
| Результат исследования | Итоговый вывод о совокупности испытаний по пробам образца в одной лаборатории |
| Протокол | Итоговый документ, объединяющий образцы с заключением |
| Заключение | Текстовый вывод, который прикладывается к протоколу |
| Роль | Должность сотрудника, определяющая его возможности в системе |
| Доктор | Человек, который проводит испытания в лаборатории |
| Лаборант | Человек, который относится к определенной лаборатории и может просматривать данные по своей лаборатории |
| Санитарный врач | Лицо, которое собирает образцы на объекте и доставляет их в лабораторию |
| Дедлайн | Срок, до которого образец должен быть выпущен |
| Начальник лаборатории (НЛ) | Руководитель лаборатории с регулирующей функцией, может проводить испытания при необходимости |
| Начальник филиала (НФ) | Руководитель филиала, который получает уведомления о критических событиях |
| Регистратор | Лицо, выполняющее регистрацию образцов и создание протоколов с заключениями |

## Процессы работы по ролям

### Санитарный врач

Зона ответственности: сбор образцов на объекте и создание направления.

Жизненный цикл работы:
1. Выезжает на объект, собирает образцы.
2. Оформляет направление в электронном виде.
3. Доставляет образцы и направление в филиал.
4. После импорта направления регистратором отслеживает статусы.
5. После завершения исследований просматривает результаты и протоколы.

Доступ:
1. Просмотр направлений и образцов только по своим объектам.
2. Просмотр статусов исследований (только чтение).
3. Просмотр готовых протоколов и заключений.

UI/UX ключевые экраны:
1. Список направлений.
2. Карточка направления.

### Регистратор

Зона ответственности: приёмка образцов, регистрация, создание протоколов и заключений.

Жизненный цикл работы:
1. Принимает физические образцы и электронное направление.
2. Импортирует направление в систему (`draft`).
3. Назначает типы образцов и лаборатории, переводит направление в `registered`.
4. Регистрирует образцы (`pending` -> `registered`), проставляет `received_at`, система вычисляет `deadline`.
5. При обнаружении брака переводит образец в `rejected`.
6. После завершения исследований формирует протокол с заключением.

Доступ:
1. Просмотр и редактирование направлений (`draft` -> `registered`).
2. Регистрация образцов (`pending` -> `registered` / `rejected`).
3. Назначение типов образцов и лабораторий.
4. Создание и редактирование протоколов и заключений.

UI/UX ключевые экраны:
1. Очередь на приёмку.
2. Карточка направления.
3. Форма регистрации образца.
4. Форма протокола.

### Доктор

Зона ответственности: проведение испытаний и исследований в своей лаборатории.

Жизненный цикл работы:
1. Видит исследования в статусе `ordered` по своей лаборатории.
2. Переводит исследование в работу (`ordered` -> `in_progress`).
3. Выполняет испытания (`queued` -> `in_progress` -> `completed`), при необходимости возвращает в `queued` или отклоняет.
4. После завершения всех испытаний исследование переводится в `completed`.
5. Может корректировать норму показателя.
6. Может отклонить исследование (`rejected`).
7. Может перевести образец в `rejected` при обнаружении брака.

Доступ:
1. Просмотр образцов и исследований своей лаборатории.
2. Управление испытаниями.
3. Перевод исследования `ordered` -> `in_progress`.
4. Отклонение исследований.
5. Корректировка норм показателей.

UI/UX ключевые экраны:
1. Рабочая очередь.
2. Карточка исследования.
3. Форма испытания.
4. Индикатор дедлайна.

### Лаборант

Зона ответственности: наблюдение за ходом работ в своей лаборатории (только просмотр).

Жизненный цикл работы:
1. Отслеживает состояние образцов, исследований и испытаний по своей лаборатории.
2. Эскалирует проблемные позиции доктору или начальнику лаборатории.

Доступ:
1. Просмотр направлений, образцов, исследований и испытаний только по своей лаборатории.
2. Без права изменения статусов и данных.

UI/UX ключевые экраны:
1. Дашборд лаборатории.
2. Список исследований (только чтение).
3. Карточка образца (только чтение).

### Начальник лаборатории (НЛ)

Зона ответственности: управление работой лаборатории, подтверждение исследований, закрытие образцов.

Жизненный цикл работы:
1. Подтверждает или отклоняет исследования (`draft` -> `ordered` / `rejected`).
2. При необходимости проводит испытания.
3. Может назначать новые испытания в рамках исследования.
4. После статуса `analyzed` закрывает образец (`analyzed` -> `completed`) и устанавливает `verdict`.
5. Получает уведомления о браке образцов и критических событиях.

Доступ:
1. Все действия доктора в своей лаборатории.
2. Подтверждение/отклонение исследований.
3. Закрытие образцов.
4. Назначение новых испытаний.

UI/UX ключевые экраны:
1. Очередь подтверждения.
2. Список образцов на закрытие.
3. Дашборд лаборатории.
4. Карточка образца.

### Начальник филиала (НФ)

Зона ответственности: контроль работы филиала и мониторинг критических событий.

Жизненный цикл работы:
1. Получает уведомления о браке образцов, отрицательных вердиктах и просроченных дедлайнах.
2. Добавляет образцы в список наблюдения.
3. Просматривает статистику и детали по всем лабораториям филиала.
4. Не участвует в операционных изменениях данных.

Доступ:
1. Просмотр данных по филиалу (только чтение).
2. Получение уведомлений о критических событиях.
3. Работа со списком наблюдаемых образцов.

UI/UX ключевые экраны:
1. Дашборд филиала.
2. Список наблюдаемых образцов.
3. Лента уведомлений.
4. Отчёты.

### Администратор

Зона ответственности: настройка системы, пользователи, справочники.

Жизненный цикл работы:
1. Управляет пользователями, ролями и привязками к филиалам/лабораториям.
2. Ведёт справочники: объекты, типы образцов, лаборатории, показатели, нормы, шаблоны заключений.
3. Просматривает любые данные для диагностики.

Доступ:
1. Управление пользователями и ролями.
2. Настройка справочников.
3. Просмотр всех данных без права изменения операционных статусов.

UI/UX ключевые экраны:
1. Управление пользователями.
2. Разделы справочников.
3. Журнал событий.
