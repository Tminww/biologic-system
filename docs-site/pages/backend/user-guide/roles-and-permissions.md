# Роли и права

## Назначение раздела

Раздел фиксирует, какие действия доступны пользователям в зависимости от роли.

## Базовый принцип v1

В версии `v1` используется `role-based` модель доступа.

## Типовые роли

1. `Регистратор`
2. `Сотрудник лаборатории`
3. `Руководитель лаборатории`
4. `Администратор системы`

Точный набор ролей и действий должен соответствовать данным в таблицах `roles`, `user_roles`, `role_permissions`.

## Минимальные ограничения

1. Пользователь видит только функции, разрешенные его ролями.
2. Критичные действия (изменение статусов, удаление, управление ролями) требуют явного разрешения.
3. Любой отказ в доступе возвращается в стандартном формате ошибок `RFC 9457`.
